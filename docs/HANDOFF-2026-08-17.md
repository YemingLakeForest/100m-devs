## What landed

### The economy — R85

The question was *"the first game earns £40, the second £25k, how is that sensible?"* The
answer is that the ×500 was **forced, not chosen** — §21 fixes a $50 first game and a
$50/dev/sec wage, and §4.10c requires every rung the player hires against to clear the wage.
Three canon numbers, one gap. What was actually wrong is that the rule was being applied **one
rung too early**: the garage has no payroll.

But the complaint pointed near a much worse problem than the one it named. The instrument
(`pacing.test.ts`, now printing a table rather than only asserting) found **four consecutive
prestiges buying nothing**:

| | Before | After |
|---|---|---|
| Runs 3, 4, 5, 7 | Bought nothing in any tree, earned the same $1M | Every run buys, every run ends on §4.1 |
| BP across 8 runs | Pinned near 29 | 16 → 21 → 28 → 57 → 60 → 125 → 231 |
| The ladder | 4 rungs, ×500 then ×15 then ×2 | 8 rungs, nothing over ×8, and it keeps arriving mid-game |
| §11's price ladder | A ×320 hole between $250K and $80M — exactly where runs 3–6 live | Filled by B1a, B1b, C2a; nothing steps more than 8× |

Three fixes were needed and each was a different noun being wrong:

1. **`openingRung`** — a Paradigm Shift reset `projectIndex` to 0, so every run re-climbed the
   garage. A run now opens on a game its proven company can build.
2. **`capAdjustedGrowth`** — §14.8.9's previously-refused fix 2, taken in a form that is the
   identity at cap 100, so Run 1 is unchanged to the cent (asserted).
3. **The bound on an opening game is *headcount*, not capacity.** The first cut used the cap,
   which reads well and handed run 8 the terminal 3,500-point game at two developers.

**§14.1's `R^0.2` BP exponent was deliberately left alone.** It looked like the deepest problem
and the measurement said otherwise.

## Traps 34–37 — for the register in `HANDOFF.md`

**34. A control drawn, positioned and contrast-checked can still be dead, and every gate will
pass.** §7.1 makes the HUD `pointer-events: none` with each control opting back in. A control
added to a container that never opted in renders perfectly, measures perfectly, passes contrast
— and `elementFromPoint` at its centre returns the canvas. The gate now has a
`deadControlIssues` pass that asks exactly that question. **Its first draft asked the more
obvious one** — *is the topmost element part of this button?* — and reported fourteen false
positives on the upgrades drawer, where a child span is legitimately on top. The question that
works is narrower: **does the canvas take the tap?**

**35. A node id is the save format's vocabulary, so the next free letter is not free.** Three
new tech nodes shipped as B5, B6 and C3 — the next unused ids in each branch — and §11.2's own
table already reserves B5 and B6, and §11.3 reserves C3, for canon nodes nobody has built yet.
Shipping the wrong meaning under those ids would have made the canon ones unimplementable
without a save migration. Renamed to **B1a, B1b, C2a**: an id that says where it was inserted
cannot collide with an id that was reserved.

**36. A measurement harness has bugs, and an expensive curve hides them.** The pacing harness
read its payroll buffer **once**, outside the hire loop, and spent it inside — so it could hire
1,330 people in a single frame and go bankrupt. It had been doing this the whole time; the
exponential hire cost had simply been stopping it before the error could show. **Fixing a curve
can expose a bug in the thing measuring the curve, and it will look like the fix caused it.**

**37. A comment can be true of one half of a system and be read as true of the whole.**
`heroBadges.ts` carried a note saying a renderer built against it would be drawing a floor that
could never hold a hero, because placement was gated behind Layer 2. That was true of §13.8's
**drag** and false of placement itself, which was complete. The note was correct when written,
correct in what it said, and stopped anybody looking for the twenty-line fix for months.
**When deferring work in a comment, name the thing that is missing, not the thing it blocks.**
